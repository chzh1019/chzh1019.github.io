<center>四</center>

<br/>

“阻挡<br/>不是来自高度<br/>而是来自见到了高度

<br/>城市倒塌在筑起的地方<br/>城市般的空虚动摇一切<br/>包括城市 以及<br/>一切城市般的趣味

<br/>城市的天空<br/>永远 潮湿<br/>城市的体液在喷发<br/>多情总是城市

<br/>色彩的城市多愁善感<br/>眼泪 画满双眼

<br/>城市里没有人<br/>有的只是有和没有<br/>有和没有只是废话的两面<br/>废话是废话的另一面

<br/>城市 常被自己感动”

<br/>

纸片轻轻飘起，摇摆着，缓缓落下。这有着神秘名字的五星级酒店，枕，依然松软。窗外，多雨炎热的南方新兴大城市，语言般喧闹。

<br/>

电话响了，电磁波带来陌生的声音：

“来了？正忙，晚上见，一起吃饭！”

<br/>

城市，面朝大海。风，窗外吹过，只带着城市的喧嚣，闷热而潮湿。

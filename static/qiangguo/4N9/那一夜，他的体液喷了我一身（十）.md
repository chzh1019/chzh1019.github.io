“

###### 『舞文弄墨』 [长篇]杀夫纪（又名烟花乱梦九人行）<br/>作者：喜欢数学的女孩   提交日期：2005-6-29 8:41:00

 代序：

##### 下半身愤怒的男人永远只是女人手中的蛇

<br/>

女人，是撒旦？

男人，是上帝？

 <br/>

  上帝撒旦撒旦，

  撒旦上帝上帝。

  男人永远只是，

  女人脚下的泥。

 <br/>

  女人脚下的男人，

  蛇一般爬满泥土。

  蛇毒，涂上苹果，

  苹果，绽放愤怒。

 <br/>

  女人杀死男人，无须理由，

  理由都只是画蛇添上的足。

  男人女人的战争没有国界，

  所有坟墓，女人男人构筑。

 <br/>

  女人的国度，不需要蛇头，

  男人永远走不出女人的手。

 泥土中的男人只收获愤怒，

  下半身愤怒着苹果的诅咒。

 <br/>

  蛇诅咒诅咒，撒旦撒旦，

  苹果愤怒，下半身绽放。

 男人的战争愤怒了世界，

 世界的愤怒，与蛇无关。

 <br/>

 无关的相关，相关的世界，

 男人战争女人，永远相缠。

 战争男人，女人构筑历史，

 历史的上帝，撒旦了永远。

 <br/>

  永远的撒旦，手中无蛇，

 偏又要迷离幻化出这一幕烟花乱梦九人行。

 下半身愤怒的男人永远只是女人手中的蛇，

 没有了撒旦，上帝凋零。”

<br/>

这有着神秘名字的五星级酒店里，屏幕不断抖动，清冷的光撕扯着黑暗，一片片剥落，重重摔打在厚厚的地毯上，无声的巨响划过无名的幽深，迸裂出无形的火焰，散向无边的空间，痉挛般抽搐，聚变的能量瞬间收缩，沸腾着、燃烧着，蛇涎在燃烧，苹果在燃烧，慢慢地，灰一般冷寂，蛇涎在赤红依然的苹果上冒着青烟，魂儿一样的青烟。

<br/>

窗外，

西湖，

梦迷烟雨。

（待续）
